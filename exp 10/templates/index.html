Model Selection Rationale:

In clinical screening domains, evaluating classifiers strictly by accuracy can conceal severe false negatives. We select the winning model based on ROC-AUC (Receiver Operating Characteristic - Area Under Curve) and F1-score. ROC-AUC evaluates true positive vs false positive discrimination across all classification thresholds, making it robust against class imbalance.
